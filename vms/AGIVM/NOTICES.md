# AGIVM source and content notices

The independent adapter is in `vm/agi/agivm.cpp`; the existing native AGI
interpreter, renderer and package reader are in `engine/native-game/`.
The C64 client source is in `vm/client/host/`. Files retain their source notices.

AGITEST is an authored diagnostic program generated by `scripts/build-agivm.mjs`.
Its tiny test logic is MIT-licensed along with the new module adapter and
standalone fixture encoder. It contains no Sierra game resources.

The font8x8_basic font by Daniel Hepper, derived from Marcel Sondaar/IBM fonts,
is public domain. Its source and original notice are in `vm/nes/font8x8.h`.

Original games belong to their respective rights holders. Supply your own
authorized game files. No KQ1, SQ1 or other commercial game is in this ZIP.

# Authorized demo input

On 2026-09-04 the project owner stated that they own Exidy and authorized one
ROM from this folder for distribution. The exception is limited to:

- `Crossbow.nes`
- 98,320 bytes
- SHA-256 `93c1eff05b4d39992c0fd05dce9bb3d5b8349ca3a2416717d75ef4336fc715ea`
- iNES mapper 11; 32 KiB PRG, 64 KiB CHR; no trainer or battery flag.

This records the owner's authorization, not an independent rights/title audit.
The filename alone is not proof of the game's internal identity. Boot, input,
memory, audio, and physical compatibility still require verification.

No other ROM is authorized by this exception. `../ROMS/`, derived private test
outputs, and all other `.nes` files remain ignored. The R1 SD packager uses an
explicit single-file/hash allow-list and never reads or recursively includes
the ROM library. Nothing has been committed, uploaded, or published by R1 work.

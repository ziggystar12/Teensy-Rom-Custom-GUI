Place ordinary .nes files in this folder.

NESVM lists games directly from /NESVM/ROMS. ROMs are not converted or packed
into NESVM.CRT. The current R1 core supports only a narrow Mapper 0/11 profile;
unsupported files must remain visible with a useful reason.

Launch NESVM.CRT, then use joystick port 2 Up/Down to highlight a ROM. Press
port-2 Fire or Return to run it. In a game, Return+Shift (Start+Select) returns
to this list with the same ROM highlighted. Space is NES button B.

The public kit may copy only the separately authorized Crossbow demo into this
folder. Do not copy the developer's private ROM library into a release.
